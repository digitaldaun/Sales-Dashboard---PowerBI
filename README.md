# Sales-Dashboard-PowerBI

Welcome to the Hardware Shop Sales Power BI Dashboard. This dashboard provides an interactive view of the shop’s sales performance, helping stakeholders monitor trends, identify top-performing products, and make data-driven decisions.

Features
Sales Overview: Track total sales, revenue, and number of transactions in real time.
Product Performance: View best-selling items and categories to identify trends.
Time-Based Analysis: Analyse sales by day, week, month, and year.
Regional Insights: If applicable, monitor sales by store location or region.
Interactive Filters: Drill down by product type, date, or sales channel.

Usage
Open the Power BI dashboard file.
Use the filters on the left panel to explore specific periods or product categories.
Hover over charts and visuals to view detailed tooltips with key metrics.

Purpose
This dashboard is designed to:
Provide a clear and concise overview of sales data.
Help management make informed stock and purchasing decisions.
Track seasonal trends and promotional impact.

Data Sources
The dashboard is powered by:
Sales Transactions Database
Product Catalogue
Store Details
